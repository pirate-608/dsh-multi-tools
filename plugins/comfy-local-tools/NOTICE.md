# Notices

This plugin integrates with Comfy's separately installed first-party tools:

- `comfy-mcp`: https://github.com/Comfy-Org/comfy-mcp
- `comfy-cli`: https://docs.comfy.org/agent-tools/cli

No Comfy binary, model, workflow, or upstream source tree is copied into this plugin. Users install and update those components independently and remain subject to their upstream licenses and service terms.

Hosted partner nodes and partner generation are outside the local-only boundary and can transmit user inputs or consume credits. The bundled Skill requires explicit consent before those operations.
